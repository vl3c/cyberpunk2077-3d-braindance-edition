# Nexus Mods page

- **Name:** 3D Braindance Edition
- **Version:** 0.2.0
- **Category:** Visuals and Graphics
- **Summary (short description):** Play Cyberpunk 2077 in real stereoscopic 3D using the game's own built-in 3D renderer, shown side by side for any 3D / VR headset with SBS support (half-SBS; best on a 4K screen). Unlocks the hidden in-game 3D Mode on a normal monitor. Requires RED4ext. Not VR: no head tracking, no motion controls!
- **Requirements:** RED4ext (Nexus mod 2380), add it in the Requirements tab. Off-site, optional: Virtual Desktop (https://www.vrdesktop.net/) or another half-SBS viewer.
- **File to upload:** `dist/3D-Braindance-Edition-0.2.0-Nexus.zip` (built by `./build.sh dist`; it leaves the setup scripts out, which Nexus quarantines), main file. Put the DLL's SHA-256 from the build output in the file description.
- **Description:** paste `description.bbcode` into the BBCode editor.
- **Permissions and credits:** match the MIT license: others may upload, modify, convert and use the assets in their files (with credit), commercial use allowed. Credit CD PROJEKT RED for the 3D renderer in the game.
- **Before uploading:** install from the exact zip on a clean setup (Vortex and manual) and scan it on VirusTotal.
